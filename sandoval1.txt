PROBLEMA ACTUAL - REGRESIÓN DE ACCESIBILIDAD:
Después de tu valioso feedback inicial, conseguimos resolver el problema de VoiceOver con elementos vacíos usando `autofocus=True` en los elementos principales. La solución funcionaba perfectamente cuando ejecutaba la app en modo desarrollo con `flet run --ios`. Sin embargo, ahora he descubierto que cuando compilo la aplicación para distribución (usando `flet build ipa`), el problema de accesibilidad regresa: VoiceOver vuelve a detectar contenido vacío y no lee automáticamente los elementos.

UBICACIÓN ESPECÍFICA DEL ELEMENTO VACÍO:
En la build compilada, VoiceOver detecta un elemento vacío que aparece:
- DESPUÉS del título "AVVENTURA IN CORSO" 
- ANTES del área de historia que contiene el texto "Un tranquillo villaggio di campagna con case di pietra. Gli abitanti ti salutano calorosamente..."

Este elemento vacío no existe cuando ejecuto `flet run --ios` en modo desarrollo, pero aparece consistentemente en todas las builds compiladas (release y profile mode).

DIFERENCIA CRÍTICA DESCUBIERTA:
- ✅ `flet run --ios` (modo debug): VoiceOver funciona perfectamente, `autofocus=True` es respetado
- ❌ `flet build ipa` (modo release/profile): VoiceOver encuentra contenido vacío, `autofocus=True` parece ignorado

INTENTOS DE SOLUCIÓN REALIZADOS:
He probado múltiples enfoques para resolver esta discrepancia:

1. MODOS DE COMPILACIÓN:
   - `--flutter-build-args=--release` (producción): Problema de accesibilidad
   - `--flutter-build-args=--debug` (debug): App se cierra inmediatamente al abrir
   - `--flutter-build-args=--profile` (intermedio): App funciona pero persiste problema accesibilidad

2. CONFIGURACIONES INFO.PLIST:
   ```
   --info-plist "UIAccessibilityEnabled=True"
   --info-plist "UIAccessibilityTraits=True"
   ```
   Resultado: Sin mejoras en accesibilidad

3. VERSIONES Y DEPENDENCIAS:
   - Verificado que uso exactamente la misma versión de Flet (0.28.3) en desarrollo y CI
   - Flutter versión fija 3.22.1 en ambos entornos
   - Python 3.13 en ambos entornos

4. MODIFICACIONES CÓDIGO:
   - Probado `ft.TextField` en lugar de `ft.Text` para títulos
   - Probado contenedores `ft.Semantics` (no soportados por Flet)
   - Mantenido estrategia `autofocus=True` en primeros elementos
